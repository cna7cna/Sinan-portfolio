# Muhammed Sinan — Minimalist Editorial Portfolio

A responsive five-page portfolio using the same design direction as Muhammed Ajlan's portfolio: charcoal background, ivory typography, Instrument Serif display type, Inter body text, DM Mono metadata, spacious layouts and restrained interactions.

## Pages
- index.html — Home
- about.html — Profile, education and interests
- projects.html — Weather Station Monitoring System and School Bus Tracker
- skills.html — Technical skills, tools and soft skills
- contact.html — Email, phone, resume and contact form

## Run
Extract the ZIP, open the folder in VS Code, right-click index.html and select Open with Live Server.

## Included
Original supplied photograph: public/images/muhammed-sinan-photo.jpg
Original supplied resume: public/resume.pdf

The contact form opens the visitor's default email application; no form data is stored. Content is based on the supplied resume. No social links, certifications or unlisted technologies have been invented.
